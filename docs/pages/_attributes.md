# Documentation Attributes

This file previously contained AsciiDoc attribute definitions for the documentation build system.

The attributes defined were:

| Attribute | Value |
|-----------|-------|
| `attachmentsdir` | `{moduledir}/assets/attachments` |
| `examplesdir` | `{moduledir}/examples` |
| `imagesdir` | `{moduledir}/assets/images` |
| `partialsdir` | `{moduledir}/pages/_partials` |

These paths are used by the Antora documentation toolchain to locate assets, examples, images, and partial includes within the `docs/` module.
