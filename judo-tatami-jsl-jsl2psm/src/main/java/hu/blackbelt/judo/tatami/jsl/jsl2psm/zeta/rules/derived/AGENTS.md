# AGENTS.md — `judo-tatami-jsl-jsl2psm/src/main/java/hu/blackbelt/judo/tatami/jsl/jsl2psm/zeta/rules/derived`

Zeta transformation rule sets mapping JSL calculated entity fields and relations to PSM derived data properties and navigation properties.

| File | Purpose |
| --- | --- |
| `DataPropertyRules.java` | Transformation rules converting calculated and eager primitive entity fields into PSM `DataProperty` elements. Exports `createDataProperty()`. Connects getter expressions generated by `CREATE_GETTER_EXPRESSION_FOR_DATA_TYPE`. |
| `EntityQueryRules.java` | Transformation rules mapping calculated non-eager primitive fields to PSM `DataProperty` queries without parameters. Exports `createDataPropertyForEntityQuery()`, `createGetterExpressionForEntityQuery()`. Annotates targets with query annotations. |
| `ExpressionTypeRules.java` | Lazy transformation rules compiling JSL field and relation expressions into PSM `DataExpressionType` and `ReferenceExpressionType`. Exports `createGetterExpressionForDataType()`, `createGetterExpressionForReferenceType()`. Converts expressions via `JslExpressionToJqlExpression`. |
| `NavigationPropertyRules.java` | Transformation rules converting calculated entity relations to PSM `NavigationProperty` instances. Exports `createNavigationProperty()`. Resolves getter expressions and associated cardinality elements. |
