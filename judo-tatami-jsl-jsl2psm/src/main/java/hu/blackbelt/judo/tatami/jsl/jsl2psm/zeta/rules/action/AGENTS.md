# AGENTS.md — `judo-tatami-jsl-jsl2psm/src/main/java/hu/blackbelt/judo/tatami/jsl/jsl2psm/zeta/rules/action`

Zeta transformation rule sets mapping JSL action definitions, access declarations, and relation operations to PSM operations and behaviours.

| File | Purpose |
| --- | --- |
| `AccessCreateBehaviourRules.java` | Transformation rules generating PSM create behaviour and unbound operations for JSL actor access declarations. Exports `isAccessCreateGuard(TransformationContext)`, `createCreateBehaviourForAccess(TransformationContext)`, `createCreateOperationForAccess(TransformationContext)`. Requires `ActorAccessDeclaration` with create support enabled. |
| `AccessListBehaviourRules.java` | Transformation rules creating PSM list behaviour and unbound operations for actor access declarations. Exports `isAccessListGuard(TransformationContext)`, `createListBehaviourForAccess(TransformationContext)`, `createListOperationForAccess(TransformationContext)`. Guards against access declarations lacking list permissions. |
| `AccessValidateCreateBehaviourRules.java` | Transformation rules generating validate-create behaviour and operations for actor access declarations. Exports `isAccessValidateCreateGuard(TransformationContext)`, `createValidateCreateBehaviourForAccess(TransformationContext)`, `createValidateCreateOperationForAccess(TransformationContext)`. Processes input/output parameters for draft validation. |
| `ActionRules.java` | Transformation rules mapping transfer actions to bound/unbound PSM operations across mapped and unmapped transfer objects. Exports `createEmptyOperationBody(TransformationContext)`, `createFaultParameter(TransformationContext)`, `createBoundOperationForEntityType(TransformationContext)`. Handles static, non-static, and choice action variants. |
| `DeleteBehaviourRules.java` | Transformation rules mapping JSL delete declarations to PSM delete operations and transfer operation behaviours. Exports `isDeleteBehaviourSupported(TransformationContext)`, `createDeleteOperationForEntityType(TransformationContext)`, `createDeleteBehaviourForTransferType(TransformationContext)`. Targets entities and mapped transfer objects. |
| `GetActionInputRangeBehaviourRules.java` | Transformation rules generating range-lookup operations and query customizer parameters for action inputs. Exports `isGetRangeActionInputGuard(TransformationContext)`, `createGetRangeActionInputBehaviourForTransferType(TransformationContext)`, `createGetRangeInputTypeForInputParameter(TransformationContext)`. Supports mapped and unmapped transfer declarations. |
| `GetTemplateBehaviourRules.java` | Transformation rules creating template retrieval operations and behaviour bindings for transfer types. Exports `isGetTemplateSupportedGuard(TransformationContext)`, `createGetTemplateBehaviourForTransferType(TransformationContext)`, `createGetTemplateOperationForTransferType(TransformationContext)`. Yields unbound operations returning initialized transfer instances. |
| `GetUploadTokenBehaviourRules.java` | Transformation rules generating token generation types, attributes, and operations for file upload handling. Exports `isGetUploadTokenSupportedGuard(TransformationContext)`, `createUploadTokenType(TransformationContext)`, `createGetUploadTokenOperation(TransformationContext)`. Attaches token operations to transfer declarations containing binary fields. |
| `RefreshBehaviourRules.java` | Transformation rules generating instance refresh operations and behaviours for entity and transfer types. Exports `isRefreshSupported(TransformationContext)`, `createRefreshOperationForEntityType(TransformationContext)`, `createRefreshBehaviourForTransferType(TransformationContext)`. Produces operations returning updated object state. |
| `RelationAddReferenceBehaviourRules.java` | Transformation rules creating add-reference operations for relation members in transfer types. Exports `isAddReferenceRelationBehaviour(TransformationContext)`, `createAddReferenceOperationForEntityType(TransformationContext)`, `createAddReferenceBehaviourForTransferType(TransformationContext)`. Binds collection reference append logic. |
| `RelationCreateBehaviourRules.java` | Transformation rules generating child creation operations across entity relations. Exports `isCreateRelationBehaviour(TransformationContext)`, `createCreateOperationForEntityType(TransformationContext)`, `createCreateBehaviourForTransferType(TransformationContext)`. Configures nested instance instantiation and link establishment. |
| `RelationGetRangeReferenceBehaviourRules.java` | Transformation rules creating selectable range reference query operations for transfer relations. Exports `isGetRangeRelationBehaviour(TransformationContext)`, `createGetRangeRelationBehaviourForTransferType(TransformationContext)`, `createGetRangeInputType(TransformationContext)`. Sets up query customizer and target range parameters. |
| `RelationListBehaviourRules.java` | Transformation rules mapping relation listing actions to PSM list operations and behaviours. Exports `isListRelationBehaviour(TransformationContext)`, `createListOperationForEntityType(TransformationContext)`, `createListBehaviourForTransferType(TransformationContext)`. Establishes pagination and filter inputs. |
| `RelationRemoveReferenceBehaviourRules.java` | Transformation rules creating remove-reference operations for collection relation associations. Exports `isRemoveReferenceRelationBehaviour(TransformationContext)`, `createRemoveReferenceOperationForEntityType(TransformationContext)`, `createRemoveReferenceBehaviourForTransferType(TransformationContext)`. Targets collection relations on entity and transfer types. |
| `RelationSetReferenceBehaviourRules.java` | Transformation rules creating single-reference assignment operations for relation targets. Exports `isSetReferenceRelationBehaviour(TransformationContext)`, `createSetReferenceOperationForEntityType(TransformationContext)`, `createSetReferenceBehaviourForTransferType(TransformationContext)`. Applies to scalar to-one reference associations. |
| `RelationUnsetReferenceBehaviourRules.java` | Transformation rules creating clear/unset operations for optional reference associations. Exports `isUnsetReferenceRelationBehaviour(TransformationContext)`, `createUnsetReferenceOperationForEntityType(TransformationContext)`, `createUnsetReferenceBehaviourForTransferType(TransformationContext)`. Clears target references without deleting target instances. |
| `RelationValidateCreateBehaviourRules.java` | Transformation rules generating draft validation operations for newly instantiated relation targets. Exports `isValidateCreateRelationBehaviour(TransformationContext)`, `createValidateCreateOperationForEntityType(TransformationContext)`, `createValidateCreateBehaviourForTransferType(TransformationContext)`. Checks constraints before relation commitment. |
| `UpdateBehaviourRules.java` | Transformation rules generating update operations and behaviours for entity and transfer types. Exports `isUpdateBehaviourSupported(TransformationContext)`, `createUpdateOperationForEntityType(TransformationContext)`, `createUpdateBehaviourForTransferType(TransformationContext)`. Maps transfer update payloads onto target entity properties. |
| `ValidateUpdateBehaviourRules.java` | Transformation rules creating validation operations for pending transfer updates prior to commit. Exports `isValidateUpdateBehaviourSupported(TransformationContext)`, `createValidateUpdateOperationForEntityType(TransformationContext)`, `createValidateUpdateBehaviourForTransferType(TransformationContext)`. Validates modified fields against domain constraints. |
